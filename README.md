# Code Luthier Beats

Tienda de café y té hecha con **React + Vite**, publicada en GitHub Pages:
https://dinostagno.github.io/code-luthier-beats

## Comandos

| Comando | Qué hace |
|---|---|
| `npm install` | Instala las dependencias (solo la primera vez) |
| `npm run dev` | Abre la página en tu PC para programar, con recarga al instante |
| `npm run build` | Genera la versión final en la carpeta `dist/` |
| `npm run deploy` | Compila y publica `dist/` en la rama `gh-pages` (la página pública) |

## Ramas

- `master`: el código fuente. Aquí se trabaja.
- `gh-pages`: la genera `npm run deploy` automáticamente. No se edita a mano.
